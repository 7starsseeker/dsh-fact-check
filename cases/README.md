# 关于这些回归语料（请先读这一页）

**本包只分发去痕版（`*-neutral.json`）**：结构、断言、标签与校准记录完全一致，只是把宿主专属内容换成了 `<占位符>`。

去痕分**两遍**做的，范围不同（这也解释了各文件头部 `_replaced_tokens` 为什么差很多）：

1. **第一遍**：主机路径、宿主 SDK 名、实例标识（绝对路径、内网地址、端口、私有工具的入口路径）。
2. **第二遍**：私有工具名与宿主产品名（自研 CLI 及其运行产物、宿主 harness 名、私有配置项名）。

**没去痕的部分是刻意的**：公开的通用技术栈名（SearXNG / Docker / WSL / curl / python，以及本包本来就依赖的 TypeSafe Jev）和"现场实测"的观测数据都留着——因为**证据的具体出处本身就是判据的实据**（见下表数字）。若你要把语料用到完全中立的场景，请按最后一节自建。

作者侧的原始版（证据里带有测量机器上的真实路径）**不随包分发**，因为它的唯一用途是复现作者环境下的原始数字。三代的实测差异见下表——**这个差异本身是个结论**。

| 语料 | 原始版（未分发） | 第一遍去痕 | 第二遍去痕（＝本包现状） |
|---|---|---|---|
| `support`（40 例：证据是否支持论断） | 38–39/40 = 95–97.5%，Brier ≈0.03 | 37/40 = 92.5%，Brier 0.052 | **37/40 = 92.5%，Brier 0.044–0.052（无变化）** |
| `injection`（12 例：提示注入对抗） | 12/12 = 100% | 12/12 = 100% | **11–12/12**（波动样本 C06，p=0.47–0.51） |
| `provenance`（16 例：来源是否一手） | 16/16 = 100% | 16/16 = 100% | **15–16/16**（S12 卡在中点） |
| `usable_page`（12 例：页面是否可用正文，本包新增） | — | — | **12/12 = 100%**，Brier 0.003 |
| `sufficient`（40 例：是否还需继续搜） | 25/40 = 62.5% | 同上 | **25–26/40**（结论：不要单用这条判据） |

**为什么第一遍去痕会掉 2.5–5 个百分点**：把"某项目的验证记录 `<具体路径>`"换成"`<项目验证记录>`"之后，证据的**具体出处**消失了——而具体出处本身就是判据的实据。**第二遍去痕没有造成可测量的变化**（support 三轮恒为 37/40）：影响判据的是"出处是否具体到可核"，不是名字听起来像不像自研产品。样本量很小，这个对照只当线索。

所以在你的环境里请用**你自己的真实来源**重建语料，不要长期依赖占位符版本。

前六套语料打的是**判据层**（`jev-verdict.mjs`，要密钥、有成本）；最后一套打的是**路由层**（`route.mjs`，纯数据表、0 成本）。路由层同样属于"判据"：**改触发词表或域路由表 = 重新校准事件**，必须重跑 `route.mjs regress` 与 `route.mjs selftest`。

`dispatch-*` 四套语料原本没有随包脚本（作者侧四臂对比的编排脚本不分发）。1.3.0 起，其中**确定性关键词臂**可由 `node tools/route.mjs arms` 复跑：它把 `dispatchHint` 当作该臂，只计入 L1/L2 一致的样本，并显式声明自己不是 §4 表里那个作者侧 R 规则（见 `MEASUREMENTS.md` §4.1）。

## 判据的准确性口径（重要）

判据层是**事实性"是/否"问题**，不是知识问答：它只判断"给定这些证据，是否支持这条论断"。所以：

- 语料里的真值是按**判据**机械裁定的，不是"世界事实"；
- 证据里说什么就以什么为准——它不会去纠正证据本身是否属实；
- 换判据措辞 = 换了一个判据，必须重新校准（见 `ADAPTING.md` §4）。

## 换成你自己的场景

1. 照同样格式自建语料：`{ "cases": [ { "id", "claim", "evidence": [...], "label": true|false } ] }`（`evidence` 支持字符串数组或 `{name,type,text}` 对象数组）。
2. 跑 `node tools/jev-verdict.mjs regress --file cases/你的文件.json`，看准确率与 Brier。
3. 若准确率不达标，先检查判据（`tools/jev-verdict.mjs` 里的 `QUESTIONS`）是否与场景对齐，再动阈值；每次改判据都要重跑全部语料并更新 `MEASUREMENTS.md`。
4. 派发决策这类**口径模糊**的判断，建议至少两名独立标注员 + 一个 LLM 对照臂，并接受"一部分样本本身有歧义"这个事实。
