# 中英双语：固定标题与术语

> **本文件是 on-demand 参照，不是流程的一部分。** 写英文报告时才读；写中文时一个 token 都不花。
> 正文（`SKILL.md` 的 Step 4b）只保留各骨架的英文标题**序列**——那是骨架级的锚点，够用。这里放的是**段内**的固定写法：档位词、双轨、分档小标题、表头、禁引用警示。

## 0. 先记这三条

1. **默认跟随提问语言**；用户点名要某种语言则覆盖。
2. **同一份报告只用一种语言**——按二级标题多数判定。`## One-line verdict` 下面写中文正文，两边都对不上，出图时会出现半中半英。
3. **英文标签只是显示层**：`Confirmed` 与「已证实」在出图侧映射到同一个内部判定，颜色、图标、语义完全相同。**不要为了配图去改判定用词**；反过来，也不要把中文判定换成英文词以求"更专业"。

## 1. 裁决（4-V）的二级标题

| 中文模板标题 | 英文报告必须用 |
|---|---|
| `## 一句话结论` | `## One-line verdict` |
| `## 始末 / 事实概要` | `## What happened` |
| `## 哪些是真的、哪些是假的` | `## What is true, what is false` |
| `## 国内外视角` | `## Domestic vs international coverage` |
| `## 利益相关与污染面（标注，不参与定档）` | `## Stakeholders and contamination surface (annotation only, no downgrade)` |
| `## 为什么会这样` | `## Why this happened` |
| `## 一句话总结` | `## One-sentence takeaway` |
| `## 本次未能核实到的` | `## What we could not verify` |
| `## 来源（编号附录）` | `## Sources (numbered appendix)` |
| `## 工具与能力使用情况` | `## Tools and capabilities used` |

出图侧（`dsh-card-export` 的 `report-card`）按 `One-line verdict` / `What is true, what is false` / `Sources` 命中**任意两段**才走结论卡。自创近义词（`Verdict`、`Summary of findings`、`References`），图照样能出，但会退化成普通文档：没有档位徽标、没有双轨、没有逐条断言分档。

> **只有裁决骨架有出图锚点。** 其余骨架没有对齐锚点，出图会退化成普通文档——这是预期行为，不是缺陷；**不要为了出图给其它骨架自创锚点**，那会让解析器误判成裁决。

## 2. 段内固定写法

左列的中文**不要直译成别的近义词**。

| 中文写法 | 英文写法 |
|---|---|
| `**已证实**` / `**很可能属实**` / `**未证实**` / `**证伪**` / `**无法核实**` | `**Confirmed**` / `**Likely true**` / `**Unconfirmed**` / `**False**` / `**Unverifiable**` |
| `· 置信度 高 / 中高 / 中 / 低` | `· Confidence: high / medium-high / medium / low` |
| `定档：**A / 高**（范围）；**B / 中**（范围）` | `Tiering: **Confirmed / high** (scope); **Unconfirmed / medium** (scope)` |
| `**甲轨（默认口径，正式结论）**：` | `**Rail A (default basis, formal verdict)**:` |
| `**乙轨（保守口径，…）**：` | `**Rail B (conservative reading, recomputed after removing annotated sources)**:` |
| `**✅ 已证实 — 事实级**` | `**✅ Confirmed — fact level**` |
| `**✅ 已证实 — 解读级**（…）` | `**✅ Confirmed — interpretation level (not the fact itself)**` |
| `**⚠️ 未证实**（单一来源或无法溯源）` | `**⚠️ Unconfirmed** (single source or untraceable)` |
| `**❓ 无法裁定**（各来源矛盾且无法判定）` | `**❓ Unresolved** (sources conflict, no way to adjudicate)` |
| `> 不得在任何转述中被当作事实引用` | `> Must not be cited as fact in any retelling` |
| `- 国内渠道：` / `- 国外渠道：` / `- 差异说明：` | `- Domestic channels:` / `- International channels:` / `- Difference:` |
| `**核查时间**：` | `**Checked on**:` |

**档位词只有那五个。** 写 `Partly true`、`Busted`、`Mixed` 之类，解析器认不出，徽标会落到 `Unverifiable`——那是**判定错误**，不是排版问题。

利益相关那张表的四列表头同样固定：`来源 / 层级 / 可观察依据 / 乙轨动作` → `Source / Level / Observable basis / Rail B action`。

## 3. 因果机制（4-C）的段内写法

三个入口共用的尾段与强度标注：

| 中文写法 | 英文写法 |
|---|---|
| `## 排除的成因` | `## Ruled out` |
| `## 未发生的环节` | `## Stages that did not occur` |
| `## 边界与反例` | `## Limits and counterexamples` |
| `## 未知` | `## Open questions` |
| `## 落地概率` | `## Probability of enactment` |
| `## 反向 / 对冲` | `## Countervailing effects` |
| `可能性：<高/中/低>` | `Likelihood: <high/medium/low>` |
| `置信度：<高/中/低>（依据：…）` | `Confidence: <high/medium/low> (basis: …)` |

> **两个词分两句写。** `Likelihood:` 说的是"这件事有多大可能"，`Confidence:` 说的是"我对这个判断的证据基础有多硬"。合并成 "very likely with high confidence" 会让读者分不清在限定哪一维（ICD 203 的原始纪律）。
> 时间线节点的档位沿用裁决那五个词（`Confirmed` / `Unconfirmed` / `Unresolved` …），不要另造一套。

## 4. 其余骨架的段内写法

| 中文写法 | 英文写法 |
|---|---|
| `确定性：多源一致 / 口径依赖 / 单源 / 推断` | `Certainty: multi-source / basis-dependent / single-source / inference` |
| `## 可比性检验` | `## Comparability check` |
| `## 不可比` | `## Not comparable` |
| `## 分场景结论` | `## Scenario conclusions` |
| `## 口径差异` | `## Basis differences` |
| `## 数据截至` | `## Data as of` |
| `（建议）` | `(recommendation)` |
| `（推断）` | `(inference)` |

## 5. 专名对照表与译名分歧表

中文报告与英文报告的**表头方向不同**，因为正文用哪一种语言，表就补哪一种原文：

| 报告语言 | 正文用 | 对照表列 |
|---|---|---|
| 中文 | 中文名 | `中文译法 / 来源性质 / 流通范围 / 采信` |
| 英文 | 英文名 | `English / Origin / Where it circulates / Adopted` |

**有分歧的专名占多行**：一个专名的每种流通译法各占一行，标清来源性质（official zh-CN / official zh-TW / fan translation / community）与流通站点。英文名与日文名可以另起一张对照表，或并列进同一行。

无法核实来源性质的译法，在「来源性质」列写 `unknown`，并在报告的缺口一节说明查到了哪一步。**不要把百科条目名当成官方译名**——条目名是编辑选择。

**同词异译再记一句**：同一外文词可能有多套互不通用的定译（Monroe → 门罗主义 / 玛丽莲·梦露）。表里遇到这种情况，在「中文译法」列各占一行，并在「来源性质」列写 `same source term, different referent`——不要合并成一行，也不要为了"统一"改掉其中一个。

**一指多名 × 一名多指**（史料、古籍、跨语种转写）：这时不要用译名分歧表，改用两张表——

- **实体表**（主键）：`时间 / 职官或身份 / 关联事件` — 名字不进来
- **别名表**（多对多）：`别名 / 属于哪个实体 / 语种或来源`

英文报告同样处理，主键列写 `Period / Office or role / Key events`。

英文报告反向同理：同一个中文名可能有多套英文拼法（蒋介石：Chiang Kai-shek / Jiang Jieshi），按语境选，不合并。

原文引述（引号内）保持原语言，不受此表约束。
